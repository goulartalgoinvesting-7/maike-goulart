Perguntas frequentes

Preciso saber programar para usar os algoritmos? +

Não. Nossos algoritmos são entregues prontos para uso com instaladores guiados. Você só precisa conectar sua corretora via API (seguimos tutoriais passo a passo) e ativar a estratégia no painel.

Qual capital mínimo recomendado? +

Depende do algoritmo. Para estratégias de ações e mini-contratos da B3, recomendamos a partir de R$10.000. Para cripto, R$5.000 já é suficiente para operar com gestão de risco adequada.

Os resultados do backtest garantem retornos futuros? +

Não. Resultados passados não são garantia de resultados futuros. Nossos backtests são conduzidos com rigor para minimizar overfitting, mas mercados financeiros sempre envolvem risco de perda de capital.

Posso cancelar a qualquer momento? +

Sim. Nos planos mensais, você cancela com um clique no painel, sem fidelidade e sem multa. O acesso continua até o fim do período pago.

O algoritmo fica rodando no meu computador? +

Você pode rodar localmente ou em nosso servidor cloud. Recomendamos o cloud para garantir operação 24/7 sem depender da sua conexão — disponível nos planos Pro e Institucional.
